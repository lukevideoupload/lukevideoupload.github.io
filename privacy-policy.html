Privacy Policy — Luke Video Upload

Last updated: November 20, 2026

1. Who operates this tool

Luke Video Upload ("the Tool") is a web-based publishing tool for short-video creators, operated by LUKE ("the Operator"). Any TikTok creator can sign in with TikTok Login Kit and authorize the Tool to publish videos to their own TikTok account.

2. Information the Tool accesses

Through TikTok's official APIs, and only for the TikTok account of the creator who signed in and authorized the Tool, the Tool accesses:

  • Basic account information (user ID, display name, avatar) via the user.info.basic scope, used only to identify the signed-in creator and confirm which account a video will be published to.
  • OAuth access tokens and refresh tokens issued by TikTok for the authorized creator's account, used only to authenticate API requests made by the Tool on that creator's behalf.
  • The video files the creator chooses to publish, which the Tool transfers to TikTok via the video.upload and video.publish scopes.

3. Information the Tool does NOT collect

The Tool does not collect, access, or store information about any TikTok user other than the creator who authorized it. It does not track visitors, does not use cookies or analytics, and does not collect names, email addresses, or contact details of any third party.

4. How information is used

The information above is used for a single purpose: uploading and publishing the authorized creator's own original videos to that creator's own TikTok account. It is never used for advertising, profiling, or any other purpose.

5. Sharing

The Operator does not sell, rent, or share any information accessed by the Tool with any third party. Video files and account information are exchanged only with TikTok's official API servers as part of the publishing process.

6. Storage and security

Access tokens are stored securely, protected by file permissions, and are never published. This website is hosted on GitHub Pages; GitHub may process technical data (such as IP addresses) as described in GitHub's own privacy statement.

7. Deletion

A creator can revoke the Tool's access at any time from the TikTok app's settings (Manage connected apps), which immediately invalidates the stored tokens. A creator may also contact the Operator below to request deletion of any stored tokens for their account.

8. Changes

This policy may be updated when the Tool changes. The current version will always be posted on this page.
