Privacy Policy — Luke Video Upload

Last updated: November 9, 2026

1. Who operates this tool

Luke Video Upload ("the Tool") is a private, personal software tool created and operated by an individual creator, LUKE ("the Operator"), for publishing the Operator's own videos to the Operator's own TikTok accounts. The Tool has no other users.

2. Information the Tool accesses

Through TikTok's official APIs, and only for the Operator's own TikTok accounts, the Tool accesses:

  • Basic account information (user ID, display name, avatar) via the user.info.basic scope, used only to confirm which of the Operator's accounts a video will be published to.
  • OAuth access tokens and refresh tokens issued by TikTok for the Operator's accounts, used only to authenticate API requests made by the Tool.
  • The video files the Operator chooses to publish, which the Tool transfers to TikTok via the video.upload and video.publish scopes.

3. Information the Tool does NOT collect

The Tool does not collect, access, or store information about any other TikTok user. It does not track visitors, does not use cookies or analytics, and does not collect names, email addresses, or contact details of any third party.

4. How information is used

The information above is used for a single purpose: uploading and publishing the Operator's own original videos to the Operator's own TikTok accounts. It is never used for advertising, profiling, or any other purpose.

5. Sharing

The Operator does not sell, rent, or share any information accessed by the Tool with any third party. Video files and account information are exchanged only with TikTok's official API servers as part of the publishing process.

6. Storage and security

Access tokens are stored only on the Operator's own computer, protected by file permissions, and are never published. This website is hosted on GitHub Pages; GitHub may process technical data (such as IP addresses) as described in GitHub's own privacy statement.

7. Deletion

The Operator can revoke the Tool's access at any time from the TikTok app's settings (Manage connected apps), which immediately invalidates the stored tokens. Because the Tool holds no third-party data, there is no user data to request deletion of. Questions may be sent to the contact below.

8. Changes

This policy may be updated when the Tool changes. The current version will always be posted on this page.
